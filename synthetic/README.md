# synthetic — 가짜 데이터

`devices.csv`: 가짜 기기 20대 (업체 6곳). **업체명 · 제조번호 · 형식승인번호 · 접수번호는 전부 지어낸 값**이다. 실제 견본은 여기에 넣지 않는다.

- 같은 제조번호가 두 업체에 있다 (`A100-0007` — 가나다테크 · 차카타환경): PI-01 "같은 제조번호가 여러 업체" 경우 확인용
- 공백 · 기호가 있는 제조번호 (`SN 55/7`), 작년 접수번호가 없는 기기, 피토관이 없는 기기도 섞여 있다
- `aliases`는 `;`로 나눈 업체 별칭 (㈜/(주)/영문/약칭)

불러오기: `cd backend && .venv/bin/python -m app.seed ../synthetic/devices.csv` (여러 번 해도 중복되지 않음)

칸 형식은 USB CSV 일괄 등록(#10)에서도 그대로 쓴다.
